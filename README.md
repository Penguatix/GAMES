# Game Time 🎮

A central landing page built to host and link all of my custom-developed web games. This acts as the main directory, providing a sleek, modern UI for users to select which game they want to play.

## 🚀 Features
- Clean, modern dark-mode aesthetic.
- Responsive flexbox layout that scales for desktop and mobile screens.
- Interactive hover states and smooth CSS transitions.
- Serves as the central hub linking to separate, standalone game repositories.

## 🛠️ Tech Stack
- **HTML5** for structural layout
- **CSS3** for styling, typography, and visual effects
